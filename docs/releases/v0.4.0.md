# DynaMix 0.4.0

## New

- Render a complete set to one continuous stereo WAV from the final Set Builder step.
- Choose 44.1 or 48 kHz and 16, 24 or 32-bit PCM; defaults are 44.1 kHz and 24-bit.
- The render follows the set order, planned transitions, configured FX and the existing pre-master source choice. It runs in the background with progress and can be stopped.

## Notes

- WAV output is saved to the selected path, defaulting to the project `exports/` folder.
- Existing Mixxx playlist and export behavior is unchanged.
