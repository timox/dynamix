# DynaMix 0.4.1

## New

- The final WAV mix matches the outgoing track's speed to the incoming track during each transition, using varispeed. Pitch changes with speed.
- Transition previews use the same tempo matching as the final WAV mix.

## Fixed

- Corrected the full-mix WAV transition renderer import.
- Finalizing a set list allows transition and mastering analysis; moving tracks no longer rebuilds the overview chart each time.
- The first track starts at 0 seconds by default, and transition cue positions can be adjusted.
